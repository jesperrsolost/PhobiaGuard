# Prog2007Project
Our program 'PhobiaGuard' will help people with a phobia of spider by detecting both online and in real life if an image contains a spider and censoring the spiders

## Description

Our program uses machine learning to identify spiders, and covers them with black boxes once detected to prevent the images to trigger arachnophobia.

Our main features are the monitoring modus and camera modus. Monitoring modus will allow the application to see the whole phone or a specific app and scan for spiders and censor them when it detecs spiders. Camera modus makes the user take a photo that will be scaned for spiders.

## Getting Started

### Dependencies

To build and run PhobiaGuard you will need
- Android Studio
- An Android Emulator, Pixel 8 or newer
- An emulator running Android API level 35 or higher

### Installing

1. Open Powershell or terminal
2. Clone the repository:
```
git clone https://git.ntnu.no/danielul/Prog2007Project.git
```

### Executing program

1. Open Android Studios
2. Open a new project and choice the PhobiaGuard project folder
2. Sync project with gradle files
5. Start the emulator matching the dependencies
3. Run program
